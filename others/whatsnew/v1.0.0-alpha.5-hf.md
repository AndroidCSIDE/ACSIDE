# v1.0.0-alpha.5 hotfix

### Fixes & Improvements
- Java lsp jvm settings now can be configured by creating `>acslspsettings.ini` in the root project
#### `.acslspsettings.ini` sample
  ```ini
    [java-lsp]
    Xms=2048m
    Xmx=12288m
    MetaspaceSize=1024m
    MaxMetaspaceSize=2048m
    extraArgs=-XX:+UseG1GC -XX:MaxGCPauseMillis=150 -XX:+UseStringDeduplication -XX:ParallelGCThreads=12 -XX:ConcGCThreads=3 -XX:+UnlockExperimentalVMOptions

  ```
- Fixed a splash screen hang in the armeabi-v7a variant caused by a 64-bit native alignment issue
- Fixed a bug where switching between edited files made the Undo/Redo overlay become missing and unavailable for the inactive tab.
- Fixed a bug where switching between tabs did not immediately request focus on the editor.
- Fixed an issue where the project sync process could sometimes hang indefinitely and fail to complete or update the UI state.
- Fixed an issue where project sync cache was restored with missing classpaths after app reinstallation by storing and validating the sync cache backup in the home directory gradle folder.
- Fixed a bug where switching between editor tabs reset the editor view state (zoom level, cursor selection, and scroll positions).
- Fixed preview crashes caused by uninitialized Android context when using multiplatform resources.
- Fixed missing resource errors in preview by recursively scanning the build directory to add all intermediate and packaged multiplatform assets to the resource loader.
- Fixed Compose preview crashes caused by missing versioned resource (.cvr) files by mapping generated multiplatform resource paths to their actual locations.
- Fixed a bug where undo could remove an entire typed block of code in a single step instead of smaller increments
- Fixed a bug where the active JDK version was not dynamically detected when resolving guest paths on the host.
- Fixed a bug where opening certain dropdown menus caused the soft keyboard to hide and show erratically.
- Fixed a bug where pressing Enter to insert a normal newline would instead silently accept whatever completion suggestion happened to be on top of the list even if you never selected it replacing your newline with random inserted text.
- Fixed a bug where `/root/flutter/packages/flutter_tools/gradle` being missing casuing the build in flutter to fail (https://github.com/AndroidCSIDE/ACSIDE/issues/123)
- Fixed a bug where Gradle reported missing Flutter dependencies despite their existence due to missing directory bindings.
- Fixed a bug where Kotlin LSP hang in flutter projects
- Fixed a bug where Kotlin LSP workspace export fallbacks to jdk-17 instead of dynamically retrieve it from opened project 
- Fixed a bug where gradle can't pick signing keys outside the project scope (https://github.com/AndroidCSIDE/ACSIDE/issues/131)
- Fixed a bug where editing build scripts doesn't mark cache as stale and restores stale old cache
