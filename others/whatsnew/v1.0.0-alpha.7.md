# v1.0.0-alpha.7

> **Note:** 32-bit ARM (armeabi-v7a) devices are now supported, as promised in alpha.6. This support is untested, so if anything misbehaves on one of these devices, please open an issue describing exactly what happens.

## Highlights

- **Quick Open:** Press Ctrl+P to fuzzy search project files by name
- **Editor status bar:** Git branch, diagnostics counts, cursor position and file language, with live build status
- **Multi-select file tree:** Copy, paste or delete several files at once
- **Code folding:** Fold code blocks and import blocks from the gutter
- **Google Material Look:** A Material 3 expressive style alongside Windows Fluent 2, on by default for new users
- **Kotlin language server overhaul:** Live diagnostics, faster completion and better stability in long sessions
- **Task presets:** Pin run configurations to the Run menu
- **Custom status bar:** Optional floating pill showing battery level, temperature and CPU load

---

## Editor

**New**
- Status bar showing the git branch (or NGI if git is not initialised), error and warning counts, cursor position and file language. It switches to live build status while the keyboard is open.
- Quick Open file switcher (Ctrl+P or the editor actions menu) with keyboard navigation and highlighted matches
- File path breadcrumb under the tab bar; tap any folder to browse its contents
- Landing screen showing the project name, git branch and recent files, replacing the automatic README opening
- Tab sheet listing every open tab with its folder, unsaved marker and pin
- Code folding with gutter markers and a fold marker for import blocks, with icon size and padding settings
- Option to pin line numbers while scrolling horizontally
- Ghost text preview of the selected suggestion, tappable to insert (on by default)
- Tab accepts the open suggestion, moves between snippet stops and indents, including from the extra keys row
- Slim overlay scrollbar for files of 1,000 lines or more, with drag and tap-to-jump support
- Custom status bar (Settings, Editor, Display), off by default and offered once through an announcement
- Ctrl+Shift+E to open the file tree drawer
- Project type badge (Gradle or Plain) on the empty editor screen
- Delete action in the context menu, plus reorderable context menu actions
- Copy button in the diagnostics window
- Hover documentation for Kotlin showing signatures, parameters and return types in the editor theme colours

**Improved**
- Redesigned diagnostic popup with a clearer title, expandable related locations and larger icons
- Matching bracket pairs are now highlighted more clearly
- The bottom sheet and status bar now sit above the system navigation bar
- Cleaner empty editor screen with a Quick Actions card
- Snippet placeholders use a translucent tint that stays readable in every theme
- Accepting a Kotlin function completion places the caret inside the parentheses, and Tab moves through brackets, braces and quotes
- Drawable XML files now show only the vector preview in the top bar
- Removed the in-editor line and column indicator, as the status bar now shows the cursor position

**Fixed**
- Duplicate Line copying only the text after the cursor
- Undo and redo history being lost when switching files, or failing for the rest of the session after one failed undo
- False "file changed on disk" conflicts on pinned files
- Snippets from autocomplete being indented one level too deep
- Signature help showing black text on some themes
- The diagnostics window shaking when it appeared
- Inlay hints, diagnostic squiggles and tooltips not rendering after the editor engine upgrade
- Completion window reopening after a suggestion was accepted, or opening after operators, brackets, semicolons and spaces
- The exit dialog not checking for unsaved changes
- A memory leak when closing the twin file editor
- The layout preview icon appearing for AndroidManifest.xml

## Language Servers

**New**
- Crash detection for all language servers, with a dialog offering Copy logs and Restart LSP. The Java language server no longer appears to be running after a crash.
- Parameter info for library functions, matching the correct overload, including in multi-line calls
- Hover for library functions and properties, showing full signatures, default values, return types, owning package and whether a property is val or var
- Annotation completions (such as @Preview and its import) now work immediately in files opened before the language server started

**Improved**
- Kotlin diagnostics update live while typing, with immediate syntax squiggles and semantic errors refreshing after a short pause, and saving now refreshes them instantly
- Substantial Kotlin performance gains on low-end devices, including faster completion, quicker diagnostics and no blocking while typing in large files
- Memory and garbage collection settings are now matched to the device automatically
- Capped import quick fix requests to prevent files with many unresolved references from overloading the server
- The language server now runs on the Kotlin 2.4 compiler

**Fixed**
- Kotlin language server memory growth that eventually caused it to stop responding
- Stale or permanent diagnostics, such as a squiggle stuck on an annotation
- A false error about inlining bytecode from a newer JVM target
- Auto import failing when the import was already present but commented out
- Classes available from several libraries listing only the first match; all are now shown with their packages, with the best match for the expected parameter type first
- The parameter info window covering the completion list
- Incorrect attribute prefixes in Android XML autocomplete, and false XML errors for enum checks accepting resource references
- Organize Imports and Remove Unused Imports doing nothing for Kotlin files. Organize Imports now sorts alphabetically, removes duplicates and runs immediately, without deleting file content when no package line is present.
- Format Code reordering or deleting imports; it now formats code only

## Build and Run

**New**
- Task presets in the Run menu: run a preset in one tap, pin up to 10 tasks, reorder by long-press drag and remove with the X button. Recent tasks are detected automatically.
- Build heat alert for Gradle projects: at a battery temperature of 45°C during a build, an overlay suggests lowering the Gradle heap, with an Apply button that updates gradle.properties and re-syncs. It stops alerting at 42°C, is on by default and can be disabled under Settings, Gradle service.
- Show Beta and Alpha option (Settings, Editor) so the dependency updater can suggest pre-release versions

**Improved**
- New project templates share a single Gradle wrapper (Gradle 9.8.2)
- Templates now use minimum SDK 23, avoiding mismatches with current AndroidX and Material libraries
- Updated template dependencies (AGP 9.4.1, Kotlin 2.4.21, and current AndroidX, Compose, JUnit and Guava)
- New projects default to a 512 MB heap with parallel builds and build caching enabled
- Generated project files no longer include the IDE licence header

**Fixed**
- assembleRelease failing with a task dependency error
- C and C++ files failing to run because of an incorrect output path
- Run dialog rows reporting "Selected" to screen readers when not selected
- The dependency updater long press blocking the editor context menu
