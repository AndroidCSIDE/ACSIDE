# v1.0.0-alpha.7 Patch 2

# What's new & fixed in this patch

**Added**
- Brazilian Portuguese (pt-BR) and European Portuguese (pt-PT) language support
- The Flutter SDK tab warns when CMake or NDK is missing, with a tap-for-details dialog whose Install button jumps straight to the right tab
- Launch app in the editor overflow menu for Android projects
- Compose preview can now render as a looped video, with an adjustable length and export to `/sdcard/Movies/ACSLite`
- Compose preview can now render a composable live inside the IDE

**Improved**
- Preview floating windows now expand from the toolbar tap point, with their contents fading and sliding in as the window opens
- Flutter now runs natively instead of through proot, using a [cross-compiled Flutter SDK](https://github.com/nullij/flutter-sdk-android-arm64) for noticeably faster performance
- Flutter SDK is clearly marked as unsupported on ARM-only devices instead of failing partway through the install
- Leftover Flutter preview temp files are cleaned up when the editor closes
- Build installation now shows a progress indicator in the bottom sheet header instead of a dialog
- Terminal pinch-to-zoom moves in small steps instead of jumping straight to the minimum or maximum font size
- The project drawer opens the same way on every screen size: on tablets and in landscape it now overlays the editor instead of docking, and it opens instantly instead of freezing for several seconds
- The drawer stays open when touching the editor surface on a rotated phone or tablet instead of closing itself
- Hover documentation now opens on a long press on code instead of when the cursor rests on text; mouse hover still works with a pointer and the popup sits fully above or below the editor context menu instead of sharing its space
- Signature help parameter and return types now show the short type name instead of the full package path
- Signature help and hover documentation no longer show a sharp rectangular layer behind the rounded popup in light mode

**Fixed**
- The IDE disappearing from the recents screen after building, installing and launching an app
- Crash when viewing app logs in the editor
- Crash at startup when the projects folder cannot be created
- Crash on Android 11 devices when reading display cutout corners
- Crash in the editor opening animation
- The keyboard closing itself about a second after tapping to type once the phone had been rotated, with focus jumping to the drawer menu button
- Crash in the editor when focus changed while the interface was redrawing after rotating
- The editor tab strip and extra keys row no longer use lazy lists, so a focus search cannot remasure them mid-layout after rotation
- The editor context menu flashing and jumping in size when long-pressing text while it was already showing
- Hover documentation and signature help windows escaping the editor and drawing on top of the file tree
- The editor quick actions icon using a light tint when the app is in light theme on a dark system
- Crash when rapidly tapping the editor while a dropdown or text-selection menu is open on Android 16
- Kotlin completion missing new library classes such as Icons right after a dependency sync
- Kotlin not picking up a freshly generated R class or databinding output until a restart
- R. completion after importing R never offering string, color, layout and the other nested resource classes
- R.string and R.color completion wrongly adding nested imports such as import app.R.color, which made R.color report an unresolved reference
