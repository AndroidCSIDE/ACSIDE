# v1.0.0-alpha.6

> [!WARNING]
> armeabi-v7a is not supported in this release. Support is planned for the next release.

> [!NOTE]
> ACSIDE (ACS Lite) now uses Termux Packages for the terminal backend and no longer uses PRoot by default. PRoot is not completely removed and can still be installed via PRoot-Distro.
>
> This change was made because Android's Bionic performs significantly faster than PRoot's glibc layer, without the overhead PRoot introduces. Performance after migrating to Termux Packages has been noticeably better.

## Highlights

- **Windows 11 Fluent 2 Look** – New optional visual style with smooth animations, transitions, and press feedback. Enable it in General Settings.
- **XML Layout Real Preview** – See your layouts rendered directly in the IDE, as a static image or a short video, without leaving the editor.
- **Compose Preview** – See your Compose previews directly inside the IDE, with adjustable size and density.
- **Guided Git Workflow** – Step-by-step repository onboarding, remote setup guidance, merge conflict resolution controls, and a redesigned Source Control drawer.
- **MCP Assistant Enhancements** – Edit approval mode with a diff review screen, plus "Ask AI" integration to diagnose Git errors and resolve merge conflicts.
- **Dependency Updater** – Get notified about outdated dependencies right in your build files. Long-press a notice to update all outdated dependencies at once.
