## v1.0.0-alpha.5

### New Features

- Added more bugs so I can fix them next update
- **Library template** - New project wizard template for JVM and Android libraries with Kotlin or Java source sets.
- **AI Agent custom provider** - Configure a custom OpenAI-compatible provider with your own model name, token, and base URL.
- **File tree actions menu** - Long-press file and folder actions now open as an inline dropdown at the press location.
- Problems panel & Diagnostic window: Quick fix when the language server marks a diagnostic as having fixes available; user picks an action and the editor applies it.
- Editor drawer overflow: Backup project writes a ZIP of the open project.
- Setup and SDK Manager: Manual install from device storage for Ubuntu rootfs, JDK, and Android SDK. Each component installs independently (tar.gz, tar.xz, zip, and related archive formats). Installed components show a clear success mark on the setup and SDK Manager screens.
- New support for XML language server.
- Gradle build architecture: Tooling API now runs only for project sync, then stops to free memory. Builds and task runs use the project Gradle wrapper. Reopening a project restores cached sync when build scripts are unchanged. Editing build scripts or the Gradle wrapper triggers an automatic re-sync.
- **armeabi-v7a support** (not confirmed working) — if you're an armeabi-v7a user and run into an issue, please open a new issue titled `#arm_variant - <issue title>` so I can easily track and fix them.

#### Compose preview system major internal changes

- [x] KMP Support ✅
- [x] Preview rendering uses a neutral container so user themes are shown as authored, separate from the IDE shell theme.
- [x] Compose preview resolves project resources (strings, colors, drawables, dimensions, fonts, and related values) during rendering.
- [x] Workspace awareness and better support for multi modular projects and file reference
- [x] No matter how massive the project is, you can now preview your design per-opened file.

### Fixes & Improvements

- **Android 9 crash** - fixed file watching when opening editor files on API 28 devices ( https://github.com/AndroidCSIDE/ACSIDE/issues/108 ).
- **Terminal settings** - optional PRoot seccomp bypass toggle, available in IDE settings and during setup this option should fix `function not implemented` issue in some devices.
- **SDK configuration** - NDK and CMake version forcing can be disabled from SDK Manager settings.
- **Build output install** - successful builds expose an install action in the output panel with tooling-driven APK resolution (https://github.com/AndroidCSIDE/ACSIDE/issues/107).
- **Download progress** - SDK Manager installs now use the app download bridge with visible progress.
- **Main screen responsiveness** - reduced duplicate cleanup and deferred heavy work when returning from the editor.
- **Git client** - Now supports credentials, cloning a repo uses jGit instead of Git command.
- **Editor recents cleanup** - Swiping an editor instance from recents no longer leaves the main screen frozen while background services shut down.
- **Extra keys cursor placement** - Pair symbols such as parentheses and braces now place the cursor inside the pair (https://github.com/AndroidCSIDE/ACSIDE/issues/39).
- **Storage hygiene** - post-build cleanup trims stale hybrid cache artifacts and old output logs.
- **Java completion** - fixes auto-imports for types such as data binding classes are inserted with the rest of the imports after the package line instead of above it.
- **Settings Screen** - (standalone activity): system back from a subsection returns to the main settings list instead of leaving the screen.
- **String extraction** - fixed Java/Kotlin replacement using quoted resource references instead of `getString(R.string/...)`, reduced UI freeze after confirming extraction, and added editor context menu action with a dedicated icon.
- **String extraction for XML layouts** - Hardcoded text in layout, menu, and navigation XML can be extracted to string resources from diagnostics and the editor context menu.
- **String extraction diagnostics** - hardcoded string inspections now run without requiring Kotlin or other language servers to be ready.
- **String extraction setting** - new editor setting to enable or disable string extraction (enabled by default).
- **Storage reporting** - fixed app data size being reported as double the actual disk usage due to proot bind mounts being counted twice by the system quota tracker.
- **Kotlin lsp** - Kotlin lsp jvm now can be configured in the `Main screen -> Settings -> Experimental -> Kotlin language server, click "setup" then click the settings icon in the top right`
- **Kotlin lsp** - Fixed workspace bindings issues causing Kotlin lsp to not resolve jdk & kotlin stdlib in plain editor 
- **Compose preview reload** - Subsequent previews skip compilation when build outputs are unchanged and reuse cached bytecode from disk.
- **Compose preview interaction** - Clicking buttons or other controls that show toasts no longer crashes the IDE.
- **Compose preview crashes** - Preview rendering failures are contained and shown in a copyable error dialog instead of crashing the IDE. JaCoCo-instrumented builds are handled gracefully.
- **Compose preview detection** - `@Preview` annotations are recognized with or without parentheses, including fully qualified names.
- **Editor undo and redo** - Undo and redo now read live editor state and stay reliable after leaving the Compose preview panel or switching tabs.
- **Editor quick actions** - A quick actions menu in the top bar provides line editing tools when a file is open.
- **Editor theme in light mode** - The code editor now follows the app theme (including system theme) instead of using the wrong light or dark scheme.
- **File tree open warning** - Opening binary or very large files from the file tree shows a confirmation dialog with cancel support.
- **Editor memory on project close** - Closing a project now releases open editors and tab content so memory does not keep growing across repeated open and close cycles.
- **Editor top app bar on small screens** - Toolbar actions scroll horizontally with edge fade; overflow actions stay in the more menu instead of being clipped off screen.
- **Editor drawer on small screens** - A close control at the end of the drawer tab bar lets you dismiss the drawer when the resize handle is hard to reach.
- **File tree actions** - Open terminal here jumps to the terminal tab and changes directory to the selected file or folder; duplicate file creates a numbered copy next to the original.
- **Setup manual import** - Setup no longer re-downloads JDK, Android SDK, build tools, platforms, or CMake when those components were already imported from storage.
